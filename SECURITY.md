# Security Policy

Thank you for helping keep BlazePilot secure.

## Supported Versions

Only the **latest** stable release receives security updates.

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues or discussions.**

Instead, report them privately by one of the following methods:

- GitHub Private Vulnerability Reporting.
- Email: jhanferdev@proton.me

Please include:

- BlazePilot version
- Operating system
- Steps to reproduce
- Expected behavior
- Actual behavior
- Proof of concept if available
- Logs or screenshots if relevant

## What to Expect

After receiving your report:

- I'll acknowledge receipt as soon as possible.
- I'll investigate the issue.
- If confirmed, I'll work on a fix before publicly disclosing the vulnerability whenever possible.
- You'll be credited for the report if you wish.

## Scope

Examples of security issues include:

- Crashes caused by malformed or malicious files.
- Out of bounds reads or writes.
- Memory corruption.
- Unsafe handling of symbolic links.
- Unsafe handling of archive files.
- Arbitrary code execution through crafted files.

General bugs, crashes, feature requests, and UI issues should be reported through the normal GitHub Issues page.

Thank you for helping improve BlazePilot. :3
